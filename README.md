# Venmo Receipt Scanner

Take a picture of a receipt, assign items to Venmo friends, and automatically send them a Venmo request.


## Setup
Create a <code>.env</code> file with an ACCESS_TOKEN variable. 
To get the value for this variable, you will need to obtain a bearer token from a trusted device for your Venmo account. You can find the bearer token by inspecting the <code>graphql</code> packet on Venmo's login web page as you login on a device trusted by your account.
